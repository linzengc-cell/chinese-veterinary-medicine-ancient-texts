# 中兽医与现代兽医学资料库

> 中国传统兽医学（中兽医）古代典籍数字化文本库 + 现代兽医学教材参考书目

## 项目简介

本项目旨在系统收集、整理两个兽医学术体系的文献资料：
1. **传统中兽医古籍**（texts/ 目录）：以纯文本格式保存，便于检索和二次开发
2. **现代兽医学教材书目**（modern/ 目录）：系统整理国内外兽医核心教材和参考书

中兽医拥有数千年历史，从《周礼》记载的兽医制度，到明代《元亨疗马集》的集大成，形成了独特的理论体系和丰富的临床经验。1904年北洋马医学堂建立后，西方现代兽医学系统传入中国，形成中、西两种兽医学术体系并存的格局。本项目同时收录两个体系的文献，便于比较研究和交叉参考。

## 收录范围

- **传统中兽医古籍**（texts/）：元亨疗马集、司牧安骥集、活兽慈舟、痊骥通玄论、抱犊集、养耕集、猪经大全等
- **含兽医内容的综合性农书**：齐民要术、农政全书等
- **含兽医内容的人医古籍**：肘后备急方、本草纲目等（兽医相关篇章）
- **相畜与饲养管理文献**：相马经、相牛法等
- **现代兽医学教材**（modern/）：基础兽医学、预防兽医学、临床兽医学核心教材，含中英文书目
- **执业兽医资格考试知识体系**：完整覆盖中国执业兽医考试15个科目
